Emirates ID status check

Waiting for your Emirates ID? You can check the application status on ICP's website in a minute. Here is which number to use.

Ask on WhatsApp View Emirates ID service

Which number to use

  • New Emirates ID: your application number (PRAN)
  • Renewal or replacement: your Emirates ID number (or the PRAN)

How to check

  1. Open ICP's ID card status page (icp.gov.ae, "ID Card Status")
  2. Enter the PRAN, Emirates ID number or request number
  3. Press "Check Application Status"

You can also log in to ICP smart services to see your requests, or call ICP on 600522222 (from outside the UAE +971 600522222).

Questions

Emirates ID status check: common questions

How do I check my Emirates ID status?

On ICP's ID Card Status page, enter your application number (PRAN) or, for renewal or replacement, your Emirates ID number.

What is the PRAN number?

It is your Emirates ID application number. ICP uses it to check the status of an application.

Can I check Emirates ID renewal status with my ID number?

Yes. ICP says to use your Emirates ID number for renewal and replacement applications.

Who do I call about my Emirates ID application?

ICP's call centre on 600522222, or +971 600522222 from outside the UAE. We can also check it for you on WhatsApp.
